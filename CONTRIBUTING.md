# Contributing

We welcome reproducible improvements to tracking reliability, evaluation, privacy controls and accessibility.

1. Open an issue that describes the observable problem and proposed test.
2. Work on a feature branch; add deterministic tests where possible.
3. Run `python -m pytest -q` before opening a pull request.
4. Use synthetic or properly anonymized media in public issues, PRs and test fixtures.
5. Include performance impacts, error cases, false positives and limitations in each change.

Do not contribute face-identification, watchlist linkage, person dossiers, or automatic criminality/intent attribution features. Human review and meaningful uncertainty reporting are core to this project.
